# Changelog

## v3.0 — Dashboard, History, and Settings

- Connected the dashboard to dedicated History and Settings screens.
- Added demonstration readings by field, table search, period controls, a canvas chart, and CSV export for the selected field.
- Added profile and notification controls, a reset action, and a demonstration of field management in Settings.
- Updated BioSensus branding and made dashboard image paths work when served from a subdirectory. Fixed History initialization and navigation to Settings.

## Documentation updates — 2026-10-27

- Revised project descriptions, version history, contribution guidance, and limitations for a consistent project voice.
- Documented the Pulse 1.0 and BioSensus 2.0 milestones.
- Corrected the provisional publication label `v0.1.0` to `v2.0`.
- Archived Pulse 1.0 on `history/pulse-v1.0` and added the `v1.0` and `v2.0` snapshot tags.

## v2.0 — BioSensus Frontend Prototype

- Adopted the BioSensus name to distinguish the project from LG's Pulse brand.
- Includes the BioSensus dashboard and login interfaces.
- Added project documentation, interface screenshots, and repository configuration for the first GitHub publication.

## v1.0 — Pulse Frontend Prototype

- Initial dashboard under the Pulse name.
- Includes the dashboard layout, demonstration charts, styles, and images.
- Available on the historical branch with its original six application files.
