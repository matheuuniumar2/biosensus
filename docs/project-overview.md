# Project Overview

## Concept

BioSensus is an agricultural technology project aimed at integrating weather conditions and plant physiological responses to support more informed decisions in soybean cultivation.

## Agricultural problem

Spraying decisions involve environmental conditions, plant status, and operational context. Isolated measurements can be difficult to interpret together. BioSensus proposes a unified environment that makes their relationships easier to assess.

## Proposed technology

The intended platform will combine qualified weather data, physiological observations, sensor telemetry, and analytical models. Its purpose is to turn these inputs into understandable information about crop conditions and potential spraying windows. These integrations remain planned.

## Intended audience

- Soybean producers.
- Agronomists and agricultural consultants.
- Researchers.
- Precision agriculture professionals.
- Agricultural technology companies.

## Current development

**Frontend Prototype / Early Development.** Version 3.0 includes a dashboard with History and Settings screens, plus a separate login interface. The interfaces are in Brazilian Portuguese. HTML and CSS define the presentation. JavaScript handles browser interactions, charts based on fixed arrays, and export of example readings as CSV. Images use the PNG format.

Backend services, authentication, sensor connectivity, live weather integration, AI models, historical data storage, and validated decision support remain planned capabilities.

## Long-term vision

Create a practical decision-support platform that helps agricultural producers understand crop conditions and improve the timing of field operations. Progress toward this vision requires integration, evaluation, agronomic validation, and responsible deployment.

## Project history

The project began as Pulse 1.0 and adopted the BioSensus name in version 2.0 to distinguish it from LG's Pulse brand. Version 1.0 contains the initial dashboard; version 2.0 includes the BioSensus dashboard and login interfaces. Version 3.0 adds History and Settings to the dashboard. All versions remain frontend prototypes.
