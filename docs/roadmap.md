# Development Roadmap

This roadmap describes intended directions, not delivery commitments. No dates are promised. Version 2.0 includes the initial dashboard and login interfaces.

## Phase 1: Frontend Prototype

**Status: initial artifacts present; ongoing.**

The login and dashboard establish initial layouts and basic browser interactions. Future work may review usability, accessibility, interface consistency, and navigation. These improvements belong to the next frontend development cycle.

## Phase 2: Weather Data Integration

**Status: planned.**

Select qualified weather sources, document provenance and units, integrate measurements, and handle unavailable or outdated data. Replace example values only through reviewed development.

## Phase 3: Plant Physiology Data

**Status: planned.**

Define relevant physiological indicators, measurement methods, units, quality criteria, and interpretation limits. Connect qualified crop observations to the interface.

## Phase 4: IoT and Real-Time Monitoring

**Status: planned.**

Evaluate sensor connectivity, telemetry, storage, timestamps, reliability, and access controls. Establish how missing or invalid measurements will be identified.

## Phase 5: AI-Assisted Decision Support

**Status: planned.**

Develop and evaluate analytical approaches for combining environmental and physiological information. Document assumptions, uncertainty, and evaluation results before considering operational recommendations.

## Phase 6: Validation and Deployment

**Status: planned.**

Conduct software tests, field and agronomic validation, security review, and deployment planning appropriate to actual functionality. Define intended use and limitations before operational adoption.
